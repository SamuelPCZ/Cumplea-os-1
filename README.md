# Regalo de cumpleaños 🎁

Página sencilla: abres un regalo, cae confeti y aparece una galería de 3 fotos (flechas, puntos, teclado ← → y deslizar en móvil).

## Personalizar

1. Sustituye `images/foto1.svg`, `foto2.svg` y `foto3.svg` por tus fotos (`.jpg` o `.png`) y actualiza las rutas en `index.html`.
2. Cambia los textos en `index.html` (`Momento 1`, subtítulos, etc.).
3. Opcional: edita colores en `css/style.css` (`:root`).

## Probar en local

Abre `index.html` en el navegador (doble clic o extensión Live Server).

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub (público).
2. Sube esta carpeta:
   ```bash
   git init -b main
   git add .
   git commit -m "Regalo de cumpleaños"
   git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
   git push -u origin main
   ```
3. En el repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Branch: **main**, folder: **/ (root)** → Save.
5. En unos minutos la web estará en:  
   `https://TU_USUARIO.github.io/TU_REPO/`

> Si el repo se llama `TU_USUARIO.github.io`, la URL es `https://TU_USUARIO.github.io/`.
